How a note is made.

Each note asks one thing a person running a model would want to know: what a token costs, what a format saves, whether a trick pays for itself.

Predicted first

Before a run, we write down what we expect and commit it. The note then says plainly whether it held. Wrong predictions stay in the record.

Measured, not fitted

Energy comes from the chip's own sensors, twice per run, the second pass reversed. Idle power is reported beside every figure, so you can subtract it or not.

Rerunnable

Every note ends with the commands that produced it and links to the raw files. If a number is wrong, you can find out how.
