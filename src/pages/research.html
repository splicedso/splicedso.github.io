One question per note.

Each note asks one thing a person running a model would want to know: what a token costs, what a format saves, whether a trick pays for itself. {{note_count}} so far, on three machines, with the raw files behind every number.

Predicted first

Before a run, we write down what we expect and commit it. The note then says plainly whether it held. Wrong predictions stay in the record.

Measured, not fitted

Energy comes from the chip's own sensors, twice per run, the second pass reversed. Idle power is reported beside every figure, so you can subtract it or not.

Rerunnable

Every note ends with the commands that produced it and links to the raw files. If a number is wrong, you can find out how.

Open questions

What we want to know next.

Width or depth?

Small models pay more per weight. A shape study, four small models trained on the same tokens, will say which part of the shape costs it.

Capped clocks, elsewhere

A capped shader clock cuts joules per correct answer 19 to 28% on the Strix Halo. Whether Apple silicon or the RTX laptop has a control that does the same is the next question.

Draft models that pay

Trace v1 on 35,000 prompts guesses better and no faster. One on-policy pilot is left before Trace pauses.
